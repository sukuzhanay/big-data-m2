# Big Data — guía de práctica

Material docente de ingesta, canalización y ETL. Incluye dos archivos PDF de nombre equivalente y una descripción del dataset. La cifra de escala de la descripción histórica es contexto del ejercicio, no un benchmark ejecutado por este repositorio.

## Scope

La procedencia y condiciones de reutilización del dataset deben conservarse y verificarse antes de redistribuirlo; no se atribuye la autoría de datos externos al titular del repositorio.
